01 / 定位承接

从"听见思想"到"表达思想"

开题文档已论证市场断层与四条研究主线。本材料回答下一个问题：这些命题，在产品里被做成了什么。

调研发现，72% 的人观看 TED 是为了获得新观点，但只有约 15% 的人最终输出过一个完整的观点——中间 57% 的断层，正是"看—收藏—转发—遗忘"四步循环的产物。我们把这条断层拆成四段可被产品干预的旅程，并让每一段对应一个已实现（或规划中）的功能模块。

智能荐师 → 单人对话 → 群贤论道，把抽象议题变成可对话的具体智者。
→

内化思想
与角色辩论，用可控的挑战强度逼出用户自己的立场。
→
RQ3 · 增量中
人格共创
自建角色 / 视频蒸馏人格，界定"AI 支架"与"用户自写"的边界。

RQ4 · 规划中
表达思想

核心概念一以贯之：TED Talk → My Talk。TED 是证据、人物是视角、而学生自己的观点才是最终资产。

02 / 全链路导览

一次完整的观点生长过程

以下五个界面均为当前原型真实截图，串起从"带着困惑进入"到"多方观点碰撞"的完整闭环。

255可对话思想人物
（调研期 144 → 上线 255）
~18覆盖思想领域
5意图分类维度
3核心对话模式

① 智能荐师：把模糊困惑翻译成合适的视角

用户输入一句真实困惑，系统先做意图五分类（职业 / 关系 / 成长 / 创造 / 学习，默认归入"成长"），命中领域给予加权（+0.18），再从人物库中挑出最能形成"有用分歧"的一组智者——刻意让立场彼此不完全一致，制造可供思辨的张力。

② 单人对话：与一个视角深入

选定一位智者后进入一对一对话。回答由检索增强生成（RAG）驱动，人物的思想材料被加权召回后交给大模型生成——语气与立场贴合人物，但每一句都受反幻觉护栏约束（见第 04 节）。

③ 群贤论道：让多个视角互相碰撞

同一个议题抛给多位智者，加上一位"主持人"角色调度发言顺序与追问。用户不再是接收单一答案，而是旁观一场被组织过的思想交锋——这正是从"听见"走向"内化"的关键一跃。

03 / 技术方案

四层架构，一条思想的流水线

从用户敲下一句困惑，到屏幕上浮现一位智者的回答，请求穿过四个各司其职的层。

L1 · 交互层
Web 前端
单页应用，承载首页 / 人物库 / 荐师 / 单人 / 群贤五大界面。
→
L2 · 接口层
FastAPI
三大接口统一编排：荐师、单人应答、群贤组局。
→
L3 · 知识层
SQLite 检索
255 位人物的思想材料入库，供加权召回。
→
L4 · 生成层
DeepSeek LLM
在护栏约束下生成人格化、有据可依的回答。

三大接口

接口职责关键输入
/api/recommend意图五分类 + 领域加权，推荐一组有分歧的智者question
/api/chat/respond单人对话：RAG 召回 + 人格化生成人物 + 对话历史
/api/chat/group群贤论道：多智者 + 主持人调度议题 + 智者组

三个工程亮点

1意图五分类荐师

把一句模糊困惑映射到职业/关系/成长/创造/学习五维，命中领域加权（+0.18），刻意挑选立场相异的智者以制造"有用分歧"。

2三路加权 RAG

召回打分 = 重要性 ×0.5 + 词面相关 ×0.35 + 来源可信 ×0.15，让回答既贴合人物、又有材料支撑，抑制凭空发挥。

3群贤多智者调度

主持人角色负责发言顺序与追问，把并行的多个视角组织成一场有节奏的思想交锋，而非杂乱堆叠。

04 / 伦理与边界

让 AI 当支架，不当代笔

这是一个培养"用户自己观点"的产品——所以最重要的技术决策，是明确 AI 该在哪里停手。

生成层受一组全局护栏（GLOBAL_RULES，共 6 条）约束，核心是：智者的回答须基于其真实思想材料，不臆造事实、不虚构语录，并在界面上明确标注这是"非真实人物的实时发言"。这直接回应了开题 RQ3 关于"AI 支架边界"与主题 E 的设计命题。

AI 可以给你脚手架，但墙要你自己砌。

支架的边界：AI 做什么，用户做什么

AI 可提供的四类支架

生成立场 给出反例 梳理结构 提供问题候选

AI 负责扩展视野、制造张力、提供思考的起点。

必须由用户完成的部分

My Talk 正文 最终立场

观点的核心表达由用户亲自写就，AI 仅协助；系统标识 AI 协助比例，保证"这是我的观点"这一前提不被稀释。

设计原则（回应主题 D/F）：思想人物卡默认私密，缓解公开表达的心理压力；社区定位始终坚持"以 TED 为证据、以人物为视角、以学生观点为最终资产"，而非制造名人语录的消费流。
05 / 演进路线

2026 增量：从对话走向共创

当前原型已跑通"听见 + 内化"，下一阶段的三项增量将把产品推向"人格共创"与"表达"。

自建角色

让用户从零塑造一个专属的思想人物——定义其立场、语气与知识边界，把"消费视角"升级为"创造视角"。

视频蒸馏人格

从演讲/访谈视频中蒸馏出人物的观点与表达风格，快速扩充人物库并提升人格保真度。

与角色辩论

可调挑战强度的对抗式对话，用受控的压力逼出并锤炼用户自己的立场（对应 RQ2）。
